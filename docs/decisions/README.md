# Architecture Decision Records

Short notes on *why* the project is the way it is. One file per decision, numbered, never rewritten: if a
decision changes, add a new record that supersedes the old one.

Template:

```markdown
# NNNN - Title
- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD
## Context      what problem / constraints
## Decision     what we chose
## Consequences good and bad results
```
